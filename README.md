# 英語耳 PWA v4
iPhone/Safari向けの個人用PWAです。

主な仕様:
- Lesson 01〜26
- iPhoneからページ画像・音声を追加し、端末のIndexedDBへ保存
- Practiceへ音声を割り当て、Practice名を編集
- 各Lessonの最初のページは「発音ページ」として常に表示
- 2ページ目以降は「解説ページ」として初期状態では非表示
- 非表示ページは「再表示」からいつでも戻せる
- 解説ページを隠しても、そのページや音声データ自体は削除しない
- 間違って追加した音声はLessonごとの音声一覧から削除可能
- 2ページモードは廃止
- 「本を読む」は編集UIを隠し、表示中のページだけをLesson 01→26順に読むモード
- A-Bリピート
- シャドーイング録音
- お手本／自分の声／両方の再生
- 再生速度0.5〜2倍、曲間隔、リピート
- ダークモードUI

注意:
教材画像・音声はGitHub Pagesへアップロードせず、iPhone側へ登録してください。
iPhoneで録音するにはHTTPS（GitHub Pages等）とマイク許可が必要です。
